# User Info Commands  
A set of StreamerBot commands that provide account and follow information for users in chat.

These commands are simple, reliable, and work across all platforms StreamerBot supports, with Twitch offering the strongest support.

---

## Commands Included  
- Account Age  
- Account Since  
- Follow Age  
- Follow Since  

Each command supports multiple aliases, optional targets, and full customization through C#.

---

## Account Age  
Displays how long a user has had their account.

**Commands:**  
`!accountage <full/target> <full>`  
`!accage <full/target> <full>`  

**Description:**  
Returns the age of the account.  
Can be used with or without a target.  
Adding `full` shows the complete age down to seconds.

---

## Account Since  
Shows the exact date a user created their account.

**Commands:**  
`!accountsince <target>`  
`!accsince <target>`

**Description:**  
Returns the account creation date.  
Can be used with or without a target.

---

## Follow Age  
Displays how long a user has been following the channel.

**Command:**  
`!followage <full/target> <full>`

**Description:**  
Returns the follow age.  
Can be used with or without a target.  
Adding `full` shows the complete follow duration down to seconds.

---

## Follow Since  
Shows the exact date a user followed the channel.

**Command:**  
`!followsince <target>`

**Description:**  
Returns the follow date.  
Can be used with or without a target.
