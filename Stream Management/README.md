# Set Title and Set Game Commands  
Commands that update the current stream title and game.  
Supports all platforms StreamerBot supports.

---

## Commands Included  
- Set Title  
- Set Game

---

## Set Title  
Updates the stream title for the broadcaster.

**Command:**  
`!settitle <title>`

**Description:**  
Sets the stream title to the text provided.  
Requires the title argument.

---

## Set Game  
Updates the current game/category for the broadcaster.

**Command:**  
`!setgame <game>`

**Description:**  
Sets the stream game or category to the text provided.
Requires a game argument and CORRECT SPELLING.
