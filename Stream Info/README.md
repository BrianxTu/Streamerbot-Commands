# Stream Info Commands  
Commands that return the current stream title and game.  
Supports Twitch and YouTube.

---

## Commands Included  
- Title  
- Game

---

## Title  
Returns the current stream title.

**Command:**  
`!title`

**Description:**  
Displays the current stream title from Twitch or YouTube.

---

## Game  
Returns the current stream game or category.

**Command:**  
`!game`

**Description:**  
Displays the current stream game or category from Twitch or YouTube.
