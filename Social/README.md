# Social Commands  
A set of interaction-focused StreamerBot commands designed to make chat more lively, personal, and fun.

These commands are simple, customizable, and work across all platforms StreamerBot supports.

---

## Commands Included  
- High Five  
- Hug  
- Shoutout  
- Slap  

Each command supports multiple aliases, required targets, and full customization through C#.

---

## High Five  
A friendly interaction command.

**Command:**  
`!highfive <target>`

**Description:**  
Sends a high five to the specified target. 
Target is Required

---

## Hug  
A wholesome chat interaction.

**Command:**  
`!hug <target>`

**Description:**  
Sends a hug to the specified target.
Target is Required

---

## Shoutout  
Promote another user in chat.

**Commands:**  
`!shoutout <target>`  
`!so <target>`

**Description:**  
Sends a shoutout message for the specified target.
Target is Required

---

## Slap  
For when chat needs a little chaos.

**Command:**  
`!slap <target>`

**Description:**  
Sends a slap to the specified target.
Target is Required
