# !slap

A playful command that sends a randomized slap action toward a target user on Twitch, YouTube, or Kick. The script cleans the target name, selects a slap message from one of three categories, formats it, and sends it to the correct platform chat.

## Usage
`!slap <target>`

The script randomly chooses from:
- **Positive** slap messages  
- **Neutral** slap messages  
- **Negative** slap messages  

## Example
`!slap TroubleMaker`  
→ `@UserName, slapped @TroubleMaker with a wet fish`

## Customization
Add or modify lines in the `positive`, `neutral`, or `negative` arrays to change the tone or variety of slap results.
