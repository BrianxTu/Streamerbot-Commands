# !hug

A friendly command that sends a warm hug to a target user across supported platforms. The script cleans the target name, picks a hug message, formats it, and sends it to the correct platform chat.

## Usage
`!hug <target>`

## Example
`!hug CozyFriend`  
→ `@UserName, hugged @CozyFriend`

## Customization
Add additional hug lines to `hugMessages` or modify `messageTemplate` to adjust the final output.
