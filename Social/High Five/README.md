# !highfive

A simple command that sends a playful high‑five to another user on Twitch, YouTube, or Kick. The script cleans the target name, selects a random high‑five line, formats it, and sends it to the correct platform chat.

## Usage
`!highfive <target>`

## Example
`!highfive CoolStreamer`  
→ `@UserName, high‑fived @CoolStreamer`

## Customization
Add more lines to `highFiveMessages` or adjust `messageTemplate` to change the output style.
