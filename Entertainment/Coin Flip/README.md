# !coinflip  

A simple fun command that flips a virtual coin and returns either **Heads** or **Tails**. The script randomly selects one of the two sides and sends the result to chat.

## Usage
`!coinflip`  
`!coin`  
`!flip`  
`!flipcoin`

- The command flips a coin and reports the result directly to the user.  
- All aliases behave identically.

## Example
`!coinflip`  
→ `@UserName, you flipped ... Heads`

`!flip`  
→ `@UserName, you flipped ... Tails`

## Customization
Edit `coinSides` to add more playful outcomes, or modify `messageTemplate` to change how the result is displayed.
